# Retablo section bottom spacing design

## Goal

Keep the opened retablo doors fully visible by providing more space at the bottom of their home-page section.

## Design

- Add 4rem of desktop height and bottom breathing room to the culture section.
- Preserve the existing retablo size, door animation, horizontal clipping, and mobile layout.
- Let the section extend below the viewport as needed; do not crop the doors or add horizontal scrolling.

## Validation

Update the retablo layout regression test to verify the desktop bottom-space rule and run the focused retablo tests.
